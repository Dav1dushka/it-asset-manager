# IT Asset Manager

A lightweight web application for managing a small inventory of IT devices.

The project is designed as a practical frontend exercise around asset tracking, local persistence, validation and client-side data management.

## Features

- Add devices
- Delete devices
- Search devices
- Store data in browser Local Storage
- Track device names and assigned users
- Track IP addresses
- Track device status
- Validate IPv4 addresses
- Display total device count

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## Data Model

Each asset stores:

- Device name
- Assigned user
- IPv4 address
- Status

Supported statuses:

- Active
- Inactive
- Maintenance

## What I Practiced

- DOM manipulation
- Form handling
- Input validation
- Local Storage
- Client-side search and filtering
- Working with structured JavaScript data

## Limitations

This is a client-side project. Data is stored locally in the browser and is not synchronized between users or devices.
